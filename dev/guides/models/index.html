Supported models and input files

Input files

formatread withcontains
PSS/E .raw (v33)from_psse(raw, dyr)buses, loads, fixed shunts, generators, lines, 2- and 3-winding transformers

from_psse(raw, nothing) reads a network without dynamics, for power flow alone.

Controllers are attached to their machine by bus and id, as in PSS/E.

Checking what a .dyr file uses

Real .dyr files often contain models GradPower does not implement. analyze_dyr_coverage reports, record by record, which ones are native, unsupported or without a matching generator:

using GradPower
ex  = joinpath(pkgdir(GradPower), "examples")
rep = analyze_dyr_coverage(joinpath(ex, "IEEE39.raw"), joinpath(ex, "IEEE39_gov.dyr"))
coverage_counts(rep)
Dict{Symbol, Int64} with 7 entries:
  :native      => 20
  :redirected  => 0
  :unmatched   => 0
  :active      => 20
  :duplicate   => 0
  :inactive    => 0
  :unsupported => 0

By default unsupported records are skipped with a warning, and their machine keeps running without that controller. from_psse(raw, dyr; surrogates = true) instead maps common unsupported governors and exciters (GGOV1, HYGOV, IEEEG1, EXAC, ESST, ...) onto TGOV1/SEXS stand-ins. A surrogate lets a large case run end to end. It is not the original model, and results obtained with surrogates must not be presented as a validation of it.
